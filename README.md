# 🎄 Felicitación Navideña

Esta es una **felicitación navideña interactiva** creada con HTML, CSS y JavaScript, diseñada como una pequeña experiencia visual en forma de libro que se abre.

Al interactuar con la felicitación:
- Se reproduce música navideña
- Aparece una escena cálida y festiva
- Se muestra un mensaje de buenos deseos

El proyecto está pensado para compartirse fácilmente a través de un enlace y visualizarse tanto en móvil como en escritorio.

---

## ✨ Tecnologías utilizadas

- HTML5
- CSS3 (animaciones, efectos 3D y ambientación)
- JavaScript (interacción y control de audio)
- GitHub Pages

---

## 🎶 Música

La felicitación incluye música navideña que se reproduce tras la interacción del usuario, cumpliendo las restricciones de los navegadores modernos.
